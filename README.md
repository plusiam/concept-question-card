# 개념 질문 카드 (Concept Question Card)

IB PYP 7개 명시된 개념을 활용한 탐구 질문 분류 보드. 교사가 친숙한 주제(예: 놀이터)를 제시하면 학생들이 질문을 만들고, 그 질문이 어떤 개념에 속하는지 직접 분류하며 탐구의 방향을 발견합니다.

## 학년·교과

- **대상**: 초등 5-6학년
- **교과**: IB PYP 탐구 / 개념 기반 학습 / 창의적 사고

## 명시된 개념 (7가지)

| 개념 | 한국어 | 핵심 질문 |
|---|---|---|
| Form | 형태 | 어떤 모습일까? |
| Function | 기능 | 어떻게 작동할까? |
| Causation | 원인 | 왜 이렇게 되었을까? |
| Change | 변화 | 어떻게 변하고 있을까? |
| Connection | 연결 | 무엇과 이어져 있을까? |
| Perspective | 관점 | 누구의 시선일까? |
| Responsibility | 책임 | 우리는 무엇을 해야 할까? |

## 사용 시나리오

1. **교사**: 상단 주제란을 클릭해 탐구 주제 입력 (예: 놀이터)
2. **Phase 0** — 단어 시드: 주제를 보며 떠오르는 단어를 포스트잇 카드로 추가
3. **Phase 1** — 질문 만들기: 단어 카드 클릭 또는 직접 입력해 질문 생성
4. **Phase 2** — 개념 분류: 질문 카드를 7개 개념 컬럼으로 드래그해 분류
5. **Phase 3** — 탐구 질문: 별표(★)로 핵심 질문 선택, Lines of Inquiry 완성

## 모둠 실시간 모드 (선택)

2단계 '질문과 분류'에서 한 모둠이 **같은 방에 모여 실시간으로 질문을 만들 수 있어요**. 질문 카드만 공유되고, 개념 분류·별표는 각자 기기에 남습니다. `think_gears`(생각톱니) 도구와 같은 방식입니다.

- **켜기**: `config.js`의 `BACKEND_MODE`를 `'realtime'`으로 변경 (기본값은 `'local'` — 혼자 작업).
- **교사**: 2단계 상단 바의 '교사용 ▾' → **Google로 로그인** → (관리자 승인 후) **🏫 학반 관리**에서 **학반을 한 번 만들고**(교실에 붙일 학반 QR·코드 생성), 매 수업마다 그 학반에서 **'오늘 수업 열기'**(모둠 수·주제) → 학생은 **학반 QR/코드** 하나로 들어와 그날 수업·모둠·자리를 고릅니다. 새 교사는 승인 대기(`pending`)로 시작하고, 관리자(👑)가 승인해야 학반을 만들 수 있어요.
- **학생**: 학반 코드/QR로 입장 → **오늘 수업 고르기** → 모둠·자리번호 선택 → 질문을 만들면 ~2.5초 안에 모둠원 화면에 나타나요. **로그인 필요 없음.** (수업 코드 4자리로 바로 들어올 수도 있어요.)
- **권한**: 질문 수정·삭제는 **본인 자리에서 만든 것만**. 분류는 누구나 자유롭게.
- **개인정보**: 학생 실명·학번은 서버로 보내지 않아요. 질문 글과 자리번호만 저장됩니다.

> 실시간 백엔드는 plusiam의 `qar-board` Supabase 프로젝트 `concept_cards` 스키마를 사용합니다. 학생은 테이블에 직접 접근하지 않고, 접속코드로 보호된 RPC 함수만 호출합니다.

### 학급 전체 탐구목록 만들기 (모둠 결과 모으기)

모둠별 실시간 활동이 끝나면, 학급 전체가 모여 함께 탐구 질문을 골라요.

1. 교사가 '교사용 ▾ → 🏫 학반 관리'에서 각 수업(오늘 수업)의 **📄 결과 저장**으로 모둠 결과물을 내려받아요.
2. 홈 화면의 **🧺 학급 정리** 카드로 들어가 그 JSON들을 한 번에 불러오면, 모든 모둠 질문이 한 보드에 모여요(각 카드에 출처 모둠 표시).
3. 2단계에서 함께 분류하고 → 3단계에서 별표로 **탐구 질문(Lines of Inquiry)** 을 골라 완성해요.

이 모으기·정리 단계는 교사 화면(로컬)에서 진행합니다.

## 기술 스택

- HTML / CSS / Vanilla JS (빌드 도구 없음)
- [SortableJS](https://sortablejs.github.io/Sortable/) — 드래그앤드롭
- [Supabase](https://supabase.com/) — 실시간 모드 백엔드(SECURITY DEFINER RPC + 폴링, 선택)
- Google Fonts (Jua + Noto Sans KR)
- LocalStorage — 자동 저장 / 실시간 모드의 분류·별표 보관
