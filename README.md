# 개념 질문 카드 (Concept Question Card)

IB PYP 7개 핵심 개념을 활용한 탐구 질문 분류 보드. 교사가 친숙한 주제(예: 놀이터)를 제시하면 학생들이 질문을 만들고, 그 질문이 어떤 개념에 속하는지 직접 분류하며 탐구의 방향을 발견합니다.

## 학년·교과

- **대상**: 초등 5-6학년
- **교과**: IB PYP 탐구 / 개념 기반 학습 / 창의적 사고

## 핵심 개념 (7가지)

| 개념 | 한국어 | 핵심 질문 |
|---|---|---|
| Form | 형태 | 어떤 모습일까? |
| Function | 기능 | 어떻게 작동할까? |
| Causation | 원인 | 왜 이렇게 되었을까? |
| Change | 변화 | 어떻게 변하고 있을까? |
| Connection | 연결 | 무엇과 이어져 있을까? |
| Perspective | 관점 | 누구의 시선일까? |
| Responsibility | 책임 | 우리는 무엇을 해야 할까? |

## 사용 시나리오

1. **교사**: 상단 주제란을 클릭해 탐구 주제 입력 (예: 놀이터)
2. **Phase 0** — 단어 시드: 주제를 보며 떠오르는 단어를 포스트잇 카드로 추가
3. **Phase 1** — 질문 만들기: 단어 카드 클릭 또는 직접 입력해 질문 생성
4. **Phase 2** — 개념 분류: 질문 카드를 7개 개념 컬럼으로 드래그해 분류
5. **Phase 3** — 탐구 질문: 별표(★)로 핵심 질문 선택, Lines of Inquiry 완성
